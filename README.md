# 診療ガイドラインの投票準備：資料の読み方

診療ガイドラインの最終パネル会議で、パネリストが13分動画で全体像をつかみ、研究結果の要約と判断表を読み、推奨草案へ投票するための事前学習HTML教材です。

## 内容

- 最初に視聴する13分動画と、動画から本文への橋渡し
- 問いの整理、アウトカム、研究結果の要約、判断表、推奨草案、投票までの学習ルート
- 結果の要約表と研究ごとの結果をまとめた図の読み方
- 1000人あたりの人数差を、対照群と介入群の差として読む練習
- 大事な差の目安、判断の閾値、結果の幅、P値の二元論から離れた読み方
- 判断表の主要判断項目
- 推奨の方向・強さの判断
- 推奨なしを安易に選ばない考え方、条件付き推奨の意味、投票前チェックリスト、架空の問いでの投票演習
- 案内役キャラクター画像を使ったフレンドリーな読み進め
