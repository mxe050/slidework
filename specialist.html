専門医：今回のCPG分野の専門の方

専門知識を、エビデンスの適用範囲へつなぐ

専門医の役割は、会議を結論へ押し切ることではなく、PICO、アウトカム、比較対照、元論文、SoF表、EtDのずれを見つけ、 「このエビデンスは、今回の患者集団と診療場面にどこまで使えるか」を明確にすることです。

Core GRADEの確認へ 3つの立場に戻る

会議前の姿勢

  1. 専門経験を、全体のエビデンスより上に置かない
  2. 元論文の指摘は、確実性や推奨への影響まで述べる
  3. 患者重要アウトカムと代用アウトカムを分ける
  4. 学術的COIを自分でも点検する

Guyatt先生の視点

専門家の知識は重要ですが、それだけでは推奨は決まりません

Guyatt先生が繰り返し強調するのは、エビデンス、臨床専門性、患者の価値観を統合して判断することです。 専門医の経験は欠かせませんが、エビデンスを置き換えるものではありません。

専門家の確信は、偏りの源にもなる

専門家は、治療の実態、適応、害、現場の制約をよく知っています。一方で、自施設での成功経験、研究業績、 過去に表明した意見、特定の手技や薬剤への関与が判断を引っ張ることがあります。

金銭的COIがなくても、学術的COIやパネルの構成の偏りは残ります。自分が「すでに結論を持って会議に来ていないか」を先に点検してください。

批判的吟味は、論文を壊す作業ではない

批判的吟味は、研究の妥当性、効果の大きさ、精確性、患者重要アウトカム、適用可能性を見て、 そのエビデンスをどの患者・状況に、どの程度慎重に使えるかを明らかにする作業です。

元論文の問題点を見つけたら、「だから使えない」で止めず、SoF表の確実性、EtDの判断、推奨文の条件にどう影響するかまで言語化します。

Core GRADE資料から、専門医パネリストが特に見るところ

Core GRADE 6 SoFでは、アウトカムごとの相対効果、絶対効果、確実性、脚注を短く読める形にします。 Core GRADE 7 EtDでは、その数字を推奨へ移すときに、益・害・負担、確実性、価値観と意向、資源、公平性、受け入れやすさ、実行可能性をつなぎます。

Core GRADE資料 専門医が会議前に確認すること
Overview 「できるだけ単純に、しかし単純化しすぎず」に、最終判断を変える論点だけを会議へ持ち込む。
SoF 重大アウトカムの人数差、信頼区間、確実性、脚注が、患者に説明できる形になっているかを見る。
EtD 専門施設の実感だけでなく、一般診療での実行可能性、公平性、患者の価値観のばらつきまで反映されているかを見る。

会議前の読み方

結論から逆向きに、最後は元論文まで戻る

専門医は、推奨草案だけを読んで賛否を決めるのではなく、判断の根拠がPICO、SoF表、EtD、元論文とつながっているかを確認します。

  1. 推奨草案を読み、対象者、介入、比較、条件、注意書きが臨床的に明確か確認する。
  2. EtDで、望ましい効果、望ましくない効果、確実性、価値観、資源、公平性、受け入れやすさ、実行可能性の判断理由を見る。
  3. SoF表で、相対効果ではなく絶対効果、人数差、信頼区間、確実性、脚注を確認する。
  4. 可能であれば元論文まで確認し、対象者、介入の実態、比較対照、アウトカム定義、追跡期間、欠測、共介入、イベント数を読む。
  5. 元論文の問題を会議で出す場合は、推奨を変えるほどの問題か、注記や条件の修正で足りる問題かを分けて述べる。

元論文を読むときの注意

採用論文が少ない領域では、1本の論文を除外すると「エビデンスなし」になることがあります。 除外すべきか、確実性を下げるべきか、条件付き推奨や注記で扱うべきかを分けてください。

Core GRADE

パネリストが押さえるべき確実性評価の要点

Core GRADEの発想は、方法論的に厳密でありながら、会議で使える程度に単純にすることです。 専門医は細かい方法論に入りすぎず、推奨判断を変える論点を見つける読み方が必要です。

不精確性

まず、何について確実性を評価しているかを決めます。閾値は主に「差なし」または「患者に重要な差」です。 信頼区間がその閾値をまたぐなら、不精確性で下げることを検討します。

点推定値が大きく見えても、イベント数やサンプルサイズが少ない場合は、OISの観点からさらに慎重に扱います。

バイアスのリスク

Core GRADEでは、まず「何が起きたか」を確認し、そのうえで本当にバイアスを生みそうかを判断します。 たとえば盲検化がなくても、死亡のような客観的アウトカムでは影響が小さいことがあります。

高リスク試験と低リスク試験で結果が違うなら、低リスク試験を重視します。結果がよく似ているなら、バイアスが実際には大きく影響していない可能性も考えます。

非一貫性と間接性

I2だけで決めず、研究ごとの点推定値が臨床的な閾値のどちら側にあるかを見ます。 間接性では、対象者、介入、比較、アウトカムが今回の問いからずれていないかを確認します。

年齢、重症度、併存症などでベースラインリスクが大きく違うなら、同じ相対効果でも絶対効果と推奨が変わることがあります。

SoFとEtD

専門医が補うべきところ

SoF表とEtDは、専門医の経験を消すための表ではありません。専門医が知っている現場の情報を、パネル全体が検討できる形にするための器です。

確認箇所 専門医が見ること 発言に変えるとき
SoF表 人数差、信頼区間、確実性、脚注、主要アウトカムの抜け 「このアウトカムは患者に重要ですが、測定期間が短く、再発やQOLが見えていません」
元論文 組み入れ基準、治療内容、比較対照、共介入、欠測、解析対象 「この試験の比較対照は現在の標準治療とは少し違うため、間接性として扱う必要があります」
EtD 利益と害のバランス、価値観のばらつき、実行可能性、公平性 「専門施設では実施可能ですが、地域差が大きいため条件や注記が必要です」

発言の作り方

専門医としての強い発言を、会議で検討できる形にする

「私の施設ではよい結果です」ではなく、「この患者群では標準治療と比較した絶対効果がどの程度かを確認したいです」と述べる。

「この論文は問題がある」ではなく、「この欠測はバイアスのリスクとして確実性を下げるほどか、脚注で足りるかを確認したいです」と述べる。

「専門家ならこの治療です」ではなく、「ほとんどの患者が同じ選択をするほど利益が害と負担を上回るかを確認したいです」と述べる。
