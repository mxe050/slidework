# GRADEパネル投票準備：SR・SoF・EtDの読み方

診療ガイドラインの最終パネル会議で、パネリストがGRADEアプローチに基づくSR、SoF、EtDを読み、推奨草案へ投票するための事前学習HTML教材です。

## 内容

- CQ/PICO、アウトカム、SR、SoF、EtD、推奨草案、投票までの学習ルート
- Summary of Findings表とフォレストプロットの読み方
- 1000人あたりの絶対効果を、対照群と介入群の差として読む練習
- MID、判断の閾値、信頼区間、P値の二元論から離れた読み方
- EtD frameworkの主要判断項目
- 推奨の方向・強さの判断
- 投票前チェックリスト、架空CQでの投票演習、理解確認クイズ
